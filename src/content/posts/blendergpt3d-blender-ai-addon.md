A new open-source Blender add-on lets users create and edit 3D models simply by chatting with AI, sending either text prompts or images and getting back working bpy code. The project, hosted under BlenderGPT3D/blender-ai-addon on GitHub, has gathered 212 stars since being shared. It positions itself as a conversational interface to Blender's Python API, removing the need to hand-write bpy scripts for common modeling tasks.

![Flow diagram showing how the Blender AI add-on turns text or image input into bpy code that builds a 3D model, alongside its 212 GitHub stars.](/assets/posts/blendergpt3d-blender-ai-addon.svg)

## What does the Blender AI add-on actually do?

The add-on integrates AI chat directly into Blender's workflow, allowing users to describe what they want or upload an image and receive generated bpy code in return. This code then creates or edits 3D models inside the Blender environment. The core pitch is turning natural-language or visual input into executable Blender scripting output.

## Who is this add-on for?

This tool is aimed at Blender users, from hobbyists to developers, who want to speed up 3D modeling without manually writing Python scripts for the bpy API. Because it accepts both text and image inputs, it serves people who can describe a model verbally as well as those who have a reference image they want recreated or edited. Anyone comfortable installing a Blender add-on and interacting with an AI chat interface is a likely user.

## How does the input-to-output process work?

Based on the project description, the workflow is straightforward: a user sends text or an image describing the desired 3D model or edit, and the AI responds with working bpy code that executes the change in Blender. This closes the loop between a creative idea or visual reference and a functional 3D scene, using Blender's existing Python scripting foundation as the execution layer.

## How popular is the project right now?

The repository has reached 212 GitHub stars, found via GitHub itself at the blender-ai-addon page. No further adoption metrics, release dates, or benchmark comparisons are provided in the available material.
