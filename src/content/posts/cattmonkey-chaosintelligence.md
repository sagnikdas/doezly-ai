Chaos Intelligence is a new programming language that lets developers call AI agents the same way they call functions, combining precise computation with model-driven reasoning in a single `.chaos` program. The project, from GitHub user Cattmonkey, has reached 202 stars and is described as "source-available; no AI training."

![Chaos Intelligence Treats AI Agents as Callable Functions in a New Programming Language](/assets/posts/cattmonkey-chaosintelligence.svg)

## What is Chaos Intelligence?

Chaos Intelligence is a function-based programming language where agents are treated as callable values that can pass data, collaborate, and return results within the same program. The README frames it directly: "计算与流程写成函数，理解与生成交给智能体" (write computation and process as functions, hand understanding and generation to agents). A single `.chaos` source file can run from a terminal, a web IDE, or inside an existing project.

## How does the language actually work?

In Chaos, ordinary functions handle math and logic while `agent` blocks wrap model calls, and both can be composed freely. A basic example from the README multiplies this concept: a `twice` function that applies `add_one` twice to 40 returns `42`, run via `./chaos run hello.chaos`, and the docs note that "纯计算无需网络与模型密钥" (pure computation needs no network or model key). Agents are declared similarly:

```chaos
agent teacher {
  provider: "model",
  role: "planner",
  prompt: "用一个短例子解释输入中的编程概念。",
  tools: [],
  maxSteps: 3
}

teacher("闭包是什么？")
```

Declaring an agent does not trigger a model call — only the final invocation line executes it, and model configuration (keys, providers) is kept outside the source code via `./chaos configure --models`.

## What can you build with it?

The README lists four target use cases: composed intelligent workflows (planning, execution, and review chained together), goal-driven bots that persist state and take guidance at checkpoints, interactive pages and reports generated as program output, and systems with observable execution via event streams and a "RuntimeGraph." A third code example shows a program returning a live page:

```chaos
ui_artifact("page", "系统实时网络",
  ui_node("RuntimeGraph", [
    "真实运行状态", "radial", "project", "auto"
  ])
)
```

These pages, tables, and dashboards are described as "程序返回的值" (values returned by the program) — they can come from a function, be generated by an agent, or be embedded in a larger report, with real-time data served by an online host and offline exports marked as disconnected.

## How do developers get started, and what does it require?

Setup needs Python 3.9+, and the project ships a self-contained workflow: download `Chaos-Project.zip` from the latest release, unzip it, run `./chaos run` to confirm it outputs `42`, then run `./chaos setup --yes` followed by `./chaos` to launch the web IDE. Terminal-only users can skip the browser entirely using commands like `./chaos -c '40 + 2'`, `./chaos repl --empty`, and `./chaos ask '给我一个函数组合的短例子' --topic getting-started --stream`, where `ask` streams a model answer without modifying files. The README also points to two demo videos: a 3-minute-34-second short film, "曲线之外" ("Beyond the Curves"), featuring 5 fictional scientist agents and 3 fictional engineer agents, and a 2-minute-35-second product overview, both tied to release v0.154.4.

## Is this project open for commercial or training use?

Chaos Intelligence is labeled "source-available" rather than open-source, and the project explicitly states "no AI training," signaling the code is not intended to be used as training data for AI models. The IDE includes a "与助手编程" (pair programming with an assistant) feature that can generate inspectable, applicable code-change proposals, but the README notes model-generated content requires separate configuration and that public execution events do not include model internal reasoning.
