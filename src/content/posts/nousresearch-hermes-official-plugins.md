Nous Research has published an official plugin catalog for its Hermes Agent, bundling integrations like Home Assistant, Spotify, and a Claude Subscription DirectSDK into one installable collection. The repository, hosted at NousResearch/hermes-official-plugins, has already gathered 275 GitHub stars.

![Flow diagram showing Nous Research maintaining the hermes-official-plugins repo, which bundles Home Assistant, Spotify, and Claude Subscription DirectSDK plugins into Hermes Agent, with 275 GitHub stars.](/assets/posts/nousresearch-hermes-official-plugins.svg)

## What is hermes-official-plugins?

It is a GitHub repository containing the official plugins for Hermes Agent, built and maintained directly by Nous Research. Rather than developers hunting down and vetting third-party extensions, Nous Research now offers a maintained catalog that's "one install away." The README describes the project with the symbol ☤, signaling it as the canonical, first-party plugin source for Hermes.

## Which plugins are included?

The source material names three specific plugins: Home Assistant, Spotify, and Claude Subscription DirectSDK, with the phrase "and more" indicating additional plugins exist in the catalog beyond those listed. Home Assistant integration suggests smart-home control capabilities for Hermes Agent. Spotify points to media/music control, while Claude Subscription DirectSDK implies a direct SDK-level connection to Claude subscription services. No further technical details, version numbers, or configuration specifics are provided in the source text.

## Who maintains it and why does that matter?

The repository is built and maintained by Nous Research itself, not by independent third-party contributors. This distinguishes it as an official catalog rather than a community-sourced plugin marketplace. For developers building on Hermes Agent, an official, first-party source reduces the vetting burden typically associated with installing community plugins.
